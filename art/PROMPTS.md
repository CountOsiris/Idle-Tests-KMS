# Prompts for the monsters' pictures

Written by `python tools/monster-art.py prompts` from the lists in that file. To change
a line, change it there. How to put a finished picture in the game is in
[README.md](README.md).

## The style line

Put this in front of every prompt, so the pictures belong together:

> Dark fantasy game sprite, detailed pixel art, a single full figure seen from the side and facing left, muted earthy colours with one strong accent, lit from the upper left, soft dark outline, plain transparent background, no ground, no text, no border.
